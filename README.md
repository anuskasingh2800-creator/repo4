# Repo 4: Java Methods & Constructors

## Problems Covered
1. **MethodsDemo.java** — Method syntax, parameters, return values, recursion (factorial).
2. **MethodOverloading.java** — Compile-time polymorphism via overloaded methods.
3. **ConstructorDemo.java** — Default and parameterized constructors.

## How to Run
```bash
cd src
javac MethodsDemo.java && java MethodsDemo
javac MethodOverloading.java && java MethodOverloading
javac ConstructorDemo.java && java ConstructorDemo
```
